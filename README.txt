# GeoTagged Complaint Portal — 20% Prototype

## How to run
1. Extract the ZIP.
2. Open `index.html` in Google Chrome or Microsoft Edge.
3. Click through:
   Home → Login/Create Account → Dashboard → Report Complaint.
4. On the complaint page, click "Use My Current Location" and allow browser location access if you want to demonstrate geolocation.

## What is implemented
- Landing/home page
- Login page
- Create account page
- Citizen dashboard
- Complaint submission form
- Category and priority selection
- Browser geolocation demo
- Map-style visual prototype
- Photo upload input
- Complaint status cards
- Responsive layout

## What is intentionally not implemented yet
- SQL/database
- Real authentication
- Real complaint storage
- Real map API
- Admin/authority portal
- Backend

These can be added in later project phases.
